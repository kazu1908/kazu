# kazu

## JCBページを別ウィンドウで開く

`open_jcb_page.py` は `https://www.jcb.co.jp/premium/theclass/` を、可能な場合に別ウィンドウで開きます。

### VSCodeでの実行方法

1. Python拡張機能を有効化して、インタープリタを選択する
2. `open_jcb_page.py` を開く
3. `F5` もしくは「Run and Debug」から `Python: Open JCB THE CLASS page` を実行する

またはターミナルから直接:

```bash
python open_jcb_page.py
```
